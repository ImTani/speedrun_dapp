# Submission kit: Apostasy: Sede Vacante

Everything for the Team1 India Speedrun ("Build Anything on Avalanche") entry and for press.
All images come from the game's own code-drawn art or real captures of the running app.
No AI-generated images or audio.

## What's here

| Path | What it's for |
|---|---|
| `brand/` | Logo, wordmark, icon and colour / type references drawn from the game's own art and tokens. Use for the project logo and cover image. |
| `listing/` | Store-style listing assets: screenshots and cover art captured from the live app. |
| `press/FACT_SHEET.md` | One-page facts: pitch, genre, platform, chain, status, price, contact, links, stack. |
| `press/DESCRIPTIONS.md` | Copy-ready tagline, short (<= 280 chars), medium (~100 words) and long (~250 words) descriptions. |
| `press/FEATURES.md` | Ten one-line feature bullets. |
| `press/ONCHAIN.md` | How the on-chain part works, for a technical reader, plus live Fuji numbers (2026-10-20). |
| `press/CREDITS.md` | Developer, third-party assets and licences, tools and services, no-AI-art note. |
| `video/SHOTLIST.md` | Demo video shot list and voice-over script (target 2:30 to 2:50, limit 3:00). |
